## 🌍 Featured project: Flagvex

<div align="center">

### [flagvex.com](https://flagvex.com)

**An interactive flag encyclopedia, geography learning platform, and customizable flag quiz game that I built from scratch.**

[![Flagvex](https://img.shields.io/badge/FLAGVEX-LIVE-198A78?style=for-the-badge)](https://flagvex.com)
![Profiles](https://img.shields.io/badge/Flag_Profiles-254-384D74?style=for-the-badge)
![Modes](https://img.shields.io/badge/Game_Modes-8-563E80?style=for-the-badge)
![Development](https://img.shields.io/badge/Status-Active_Beta-5A656C?style=for-the-badge)

**[Play Flagvex](https://flagvex.com) · [Explore the Flag Archive](https://flagvex.com/archive.html) · [Read a Flag Profile](https://flagvex.com/flagarchive/argentina/)**

</div>

I started Flagvex as a simple idea: make geography and flag recognition more interesting. It has since grown into a live web product with **254 country and territory profiles**, eight game modes, searchable flag data, alternative and historical designs, and player accounts.

I handle the project end to end: researching and cleaning geographic data, designing game rules and interfaces, building features, integrating third-party SVG sources, managing deployments, and improving the experience through playtesting and user feedback.

| What I've built | Details |
| --- | --- |
| **Eight quiz modes** | Classic, Survival, Grayscale, Inverted Colors, Pixelated, Zoomed In, Coat of Arms, and Color Ratio |
| **Configurable gameplay** | Difficulty pools, multiple-choice and searchable answers, tailored distractors, and rules for unusual flag variants |
| **Flag encyclopedia** | Searchable profiles, visual and geographic filters, alternate flags, emblems, and related territories |
| **Artwork management** | Original-proportion and standardized 4:3 SVG sources, provenance tracking, and fallback rules |
| **Player experience** | Authentication, profiles, saved preferences, game statistics, and responsive light/dark interfaces |
| **Search visibility** | Custom domain, sitemap, metadata, accessibility checks, Google Search Console, and Bing Webmaster Tools |

**Tech stack:** HTML · CSS · JavaScript · Supabase · PostgreSQL / SQL · Vercel · GitHub · Google Sheets · SVG assets

The production application repository is private while the project is in development. The [live site](https://flagvex.com) is open to explore.
